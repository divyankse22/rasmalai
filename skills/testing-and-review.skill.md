# Testing and Review Skill

Before declaring a milestone complete:

## Static
- typecheck
- lint
- build

## Automated
- unit tests
- integration tests
- realtime state tests

## Manual
- desktop browser
- mobile browser
- portrait
- landscape
- refresh
- temporary disconnect
- reconnect
- second invitation
- expired invitation

## Review questions
- Can a client fake a score?
- Can one couple access another couple?
- Can two games be active accidentally?
- Can stale events corrupt state?
- Does the UI remain usable when the partner is offline?
- Does the server recover cleanly after a socket disconnect?
